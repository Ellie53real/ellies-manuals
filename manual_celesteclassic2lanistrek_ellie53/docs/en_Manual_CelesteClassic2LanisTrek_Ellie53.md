# *Celeste Classic 2: Lani's Trek*
From the game's [Celeste Wiki page](https://celeste.ink/wiki/Celeste_Classic_2): *CELESTE Classic 2: Lani's Trek* is a video game released by Maddy Thorson, Noel Berry and Lena Raine for *Celeste*'s third anniversary. It is available on the PICO-8 and itch.io for free.

The game contains five levels: Prologue (assumed), Trailhead, Glacial Caves, Golden Valley, and Destination. It features a different mountain climber than the original *Celeste Classic* or *Celeste*: this character's name is Lani, possibly a play on the name Lena (after Lena Raine).

In Archipelago, the goal of this game is to reach the Destination at the end of the game after collecting up to 16 Strawberries (you can choose how many with a YAML setting).

Locations include:
* Collecting each Strawberry
* Reaching each checkpoint flag
* Completing each level

The items are simply Strawberries, as well as 4 mechanics: the Grappling Hook, Springs, Grapple Points, and Snowballs.
