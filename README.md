This is a repository to host the Manual APWorlds I create for use with [Archipelago](https://archipelago.gg/) randomizers.
Currently, there are six games present here:
* [*Celeste Strawberry Jam*](https://github.com/Ellie53real/ellies-manuals/blob/main/manual_celestestrawberryjam_ellie53/docs/en_Manual_CelesteStrawberryJam_Ellie53.md)*
* [*Jetski Rush*](https://github.com/Ellie53real/ellies-manuals/blob/main/manual_jetskirush_ellie53/docs/en_Manual_JetskiRush_Ellie53.md)
* [*Lonely Wolf Treat: The Complete Series*](https://github.com/Ellie53real/ellies-manuals/blob/main/manual_lonelywolftreatthecompleteseries_ellie53/docs/en_Manual_LonelyWolfTreatTheCompleteSeries_Ellie53.md)
* [*Peggle Extreme*](https://github.com/Ellie53real/ellies-manuals/blob/main/manual_peggleextreme_ellie53/docs/en_Manual_PeggleExtreme_Ellie53.md)
* [*PICO PARK*](https://github.com/Ellie53real/ellies-manuals/blob/main/manual_picopark_ellie53/docs/en_Manual_PICOPARK_Ellie53.md)
* [*Super VR Ball*](https://github.com/Ellie53real/ellies-manuals/blob/main/manual_supervrball_ellie53/docs/en_Manual_SuperVRBall_Ellie53.md)
##### Games with an asterisk (*) next to them are Manuals that I do not intend to give a formal release (for a variety of reasons), and you must compile them yourself if you wish to bring them to multiworlds. Instructions on how to do this are included in the documentation for each APWorld this notice applies to.

A more general explanation of how Manual APWorlds themselves work can be found [here](https://github.com/ManualForArchipelago/Manual/blob/main/docs/faq/general.md).

A setup guide for Manuals can be found [here](https://github.com/ManualForArchipelago/Manual/blob/main/docs/play/connect-client.md).
