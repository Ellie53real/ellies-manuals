# *Celeste Strawberry Jam*
From *Celeste Strawberry Jam*'s [Gamebanana page](https://gamebanana.com/mods/424541): *Strawberry Jam* is the largest *Celeste* mod to date, featuring:
* 111 maps spread across 5 difficulties
* 1500+ playable rooms
* 9 hours of original music
* 250+ strawberries
* Stickers!

In Archipelago, there are two options for your goal with this game:
* Collect a set number of Strawberries. (the number can be configured with a YAML option)
* Beat the Beginner Heartside level, Blueberry Bay, after collecting enough Mini Hearts. (this number can *also* be configured with a YAML option)

The locations include:
* Completing maps
* Collecting Strawberries (Silver/Golden/Rainbow Berries are YAML toggleable)
* Looking into Binoculars (YAML toggleable)
* Jumping on Cars (YAML toggleable)

For the most part, the items are simply Mini Hearts, Strawberries, and unlocks for each map.
There are also, however, various traps, which involve using the Extended Variants mod that Strawberry Jam has as one of its dependencies to set particular variants for a user-determined number of rooms or deaths:
* Slow Trap (Gameplay Tweaks -> Game Speed: 0.5x)
* Fast Trap (Gameplay Tweaks -> Game Speed: 2x)
* Hiccup Trap (Gameplay Tweaks -> Hiccups every...: 2s)
* Invisible Trap (Gameplay Tweaks -> Madeline is Always Invisible: ON)
* High Gravity Trap (Movement -> Gravity: 2x + Fall speed: 2x)
* Dashless Trap (Movement -> Dash count: 0)
* Blurry Trap (Visual -> Blur Effect: 70%)
* Greyscale Trap (Visual -> Color Grading: Black & White)

Currently, this Manual only includes the Beginner lobby, but I might try to add other lobbies in at some point (if I do, they will be toggleable in the YAML options)! Truthfully, I wanted to make my own Manual for this because I had some gripes with the way any existing ones I could find were laid out...

**Important note #1: This Manual assumes that you have already unlocked the Heartside in the Beginner Lobby by completing every other map in the lobby. If you haven't, I would strongly advise doing so before bringing this into a multiworld.**
**Important note #2: Despite this Manual being here along with my other ones, I do not intend to formally release it. If you wish to bring this to a multiworld, you will have to compile the .apworld file yourself. You can do this by downloading the source code of this repository, extracting the "manual_celestestrawberryjam_ellie53" folder from the file, zipping the folder (NOT the individual contents, the folder _itself_), and then changing the .zip file's extension to .apworld.**
