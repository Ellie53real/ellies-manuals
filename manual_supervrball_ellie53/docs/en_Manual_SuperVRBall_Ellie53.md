# *Super VR Ball*
From *Super VR Ball*'s [VRChat Wiki Community page](https://wiki.vrchat.com/wiki/Community:Super_VR_Ball): *Super VR Ball* (SVRB) is a multiplayer obstacle course game world inspired by *Super Monkey Ball*. Up to 32 players navigate courses atop rolling balls to collect the most melons or reach the goal the fastest. Players can choose from up to 4 unique level packs, each with its own set of levels.

In Archipelago, the goal of this game is to complete a set number of Level Packs, the number of which can be configured with a YAML option.

Locations include:
* Completing levels
* Collecting Golden Melons and Secret Melons (both YAML-toggleable)
* Collecting the credits in Desert 6 (YAML-toggleable)
* Taking developer-intended shortcuts (also YAML-toggleable)

The items include:
* Progressive access to each Level Pack (3 items per pack - each one lets you go one world further into the pack)
* The different free ball skins (You start with a randomly chosen one, and the other ones are thrown into the pool as filler items)
* The ability to jump (Doesn't actually lock off a whole lot, but there are a couple of things that you can't do without jumping!)

Future plans:
* Add checks related to Reverse levels (will be YAML-toggleable)
* Come up with more unique filler items to reduce the number of "Melon Slice" fillers found in multiworlds
