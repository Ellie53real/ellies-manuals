# *Jetski Rush*
From *Jetski Rush*'s [VRChat Wiki Community page](https://wiki.vrchat.com/wiki/Community:Jetski_Rush): *Jetski Rush* is a cross-platform kart racing game world that can be played with up to 16 players. There are multiple courses to race on and items to use for your advantage.

In Archipelago, the goal of this game is to finish Time Trials on a set number of tracks, the number of which can be controlled with a YAML setting.

Locations include:
* Completing tracks
* Achieving different Time Trial times on each track (one easier time per track, as well as a more difficult time that can be enabled with a YAML setting)
* Finding each group of item boxes on the tracks

The items include:
* Access to each race track
* The different free jetski skins (You start with a randomly chosen one, and the other ones are thrown into the pool as filler items)
* Progressive upgrades to your jetski's speed - you start with a forced -30% speed debuff; after recieving one upgrade, you go up to only a -15% debuff, and the second one puts you back to normal speed!
